# LLhdm-go 测绘自动化系统

基于 Go 语言开发的横断面计算与图纸生成工具，专为测绘与道路工程设计打造。

[![Go Version](https://img.shields.io/badge/Go-1.21+-00ADD8?style=flat&logo=go)](https://golang.org/)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20Android-lightgrey)]()

---

## 📖 项目简介

**LLhdm-go** 是一套完整的测绘横断面自动化处理系统，从地形点云、平曲线、竖曲线、边坡、结构层到横断面生成、方量统计、DXF 图纸输出，全流程自动化。支持 **Windows / Linux / Android** 跨平台运行，**单文件部署，无需任何依赖**。

---

## ✨ 功能特性

- 平曲线正算/反算
- 竖曲线高程计算
- 地形三角网构建（Delaunay）
- 横断面切割
- 填/挖方边坡自动判断
- 结构层逐层生成
- 清表线自动偏移
- 填挖面积精确计算
- 方量统计 CSV 报表
- DXF 图纸生成（A4 图幅）
- HTML/SVG 交互式预览（支持桩号搜索、文字大小调节）
- 项目级配置文件支持

## 📁 项目结构

```
LLhdm-go/
├── main.go                 # 程序入口（交互式项目选择）
├── config/                 # 全局配置与输出生成
│   ├── config.go           # 常量 + 配置文件加载
│   ├── csv_builder.go      # CSV 报表生成
│   ├── dxf_builder.go      # DXF 图纸组装
│   └── html_builder.go     # HTML/SVG 可视化生成
├── llutil/                 # 核心算法库
│   └── llutil.go           # 平/竖曲线、面积、DXF实体、坐标转换等
├── bianpo/                 # 边坡模块
│   └── bianpo.go           # 边坡解析、查找、绝对坐标
├── jiegouceng/             # 结构层模块
│   └── jiegouceng.go       # 结构层计算、横坡管理
├── topslope/               # 路面板块模块
│   └── topslope.go         # 宽度/横坡解析与插值
├── terrain/                # 地形模块
│   └── terrain.go          # 三角网构建、空间网格、线段切割

```

## 🚀 快速开始

### 1. 编译运行

```bash
# 安装依赖
go mod tidy

# 运行程序
go run main.go

# 编译单文件
go build -ldflags="-s -w" -o LLhdm.exe   # Windows
go build -ldflags="-s -w" -o LLhdm        # Linux/macOS
```

### 2. 使用流程

1. 将项目数据放在以项目名命名的文件夹中（如 `lot1/`）
2. 运行程序，选择对应的项目序号
3. 程序自动完成所有计算，输出到 `项目名/result/` 目录

### 3. 输出成果

- `项目名.csv` — 方量统计报表
- `项目名.dxf` — 横断面图（A4 图幅）
- `项目名.html` — 交互式 SVG 预览（浏览器打开，支持文字大小调节）

## 🛠️ 数据格式说明

所有数据文件采用 UTF-8 编码，支持逗号、空格或制表符分隔。以 `;` 或 `#` 开头的行为注释行，程序会自动跳过。

### 1. 平曲线文件 `项目名.pqx`

第一行：无表头，直接数据 | 8 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 里程 | m | 该段起点里程 |
| 2 | X | m | 起点 X 坐标 |
| 3 | Y | m | 起点 Y 坐标 |
| 4 | 方位角 | 度分秒 | 十进制格式，如 181.062510 |
| 5 | 长度 | m | 该段长度 |
| 6 | 半径1 | m | 起点半径，直线为 0 |
| 7 | 半径2 | m | 终点半径，直线为 0 |
| 8 | 转向 | - | 左转 1，右转 -1 |

示例：
```
57415.250, 9635916.871, 433821.286, 181.062510, 150.000, 0, 99999999, 1
```

### 2. 竖曲线文件 `项目名.sqx`

第一行：无表头，直接数据 | 3 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 里程 | m | 变坡点里程 |
| 2 | 高程 | m | 设计高程 |
| 3 | 半径 | m | 0 表示无竖曲线 |

示例：
```
57415.250, 1269.365, 0
60000.000, 1258.000, 20000
```

### 3. 桩号表文件 `项目名.k`

第一行：无表头，直接数据 | 3 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 里程 | m | 计算桩号 |
| 2 | 左偏距 | m | 通常 0 |
| 3 | 右偏距 | m | 通常 0 |

示例：
```
57415.250, 0, 0
```

### 4. 地形点云文件 `项目名.xyz`

第一行：表头（自动跳过） | 3 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | X | m | 平面坐标 X |
| 2 | Y | m | 平面坐标 Y |
| 3 | Z | m | 高程 |

示例：
```
9635900.000, 433800.000, 1269.000
```

### 5. 路面板块文件 `项目名.leftslope` / `项目名.rightslope`

第一行：表头（自动跳过） | 桩号, 宽度1, 横坡1, 宽度2, 横坡2, ...

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 桩号 | m | 断面里程 |
| 2,4,... | 宽度 | m | 左负右正 |
| 3,5,... | 横坡 | % | 左幅负，右幅正 |

示例：
```
0, -1.5, -2.5, -5.0, -2.5
```

### 6. 边坡参数文件 `项目名.bianpo`

第一行：注释（以 `;` 开头） | 每 5 行为一组

| 行 | 格式 | 说明 |
|----|------|------|
| 1 | 起始桩号, 结束桩号 | 该段落范围 |
| 2 | leftfill, dx, dy, dx, dy, ... | 左填相对位移 |
| 3 | leftcut, dx, dy, dx, dy, ... | 左挖相对位移 |
| 4 | rightfill, dx, dy, dx, dy, ... | 右填相对位移 |
| 5 | rightcut, dx, dy, dx, dy, ... | 右挖相对位移 |

示例：
```
; 起始,结束
75300,102300
leftfill,-9.0,-4.5,-1.5,0.0,-14.0,-8.0
```

### 7. 结构层文件 `项目名.leftstructure` / `项目名.rightstructure`

第一行：注释（以 `;` 开头） | 9 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 起始桩号 | m | 配置起点 |
| 2 | 结束桩号 | m | 配置终点 |
| 3 | 层序 | - | 从 1 开始递增 |
| 4 | 层名 | - | 如 top, CRR, C1 |
| 5 | 厚度 | m | 层厚 |
| 6 | 内台阶宽 | m | 内缩宽度 |
| 7 | 内坡 | - | 内坡率（绝对值） |
| 8 | 外台阶宽 | m | 外扩宽度 |
| 9 | 外坡 | - | 外坡率（绝对值） |

示例：
```
99100,117500,1,top,0.05,0,0.0,-5,-2
```

### 8. 横坡变化文件 `项目名.leftcrossfall` / `项目名.rightcrossfall`

第一行：表头（自动跳过） | 2 列

| 列序 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 1 | 桩号 | m | 控制点里程 |
| 2 | 横坡 | % | 线性插值 |

示例：
```
0, -2.5
50000, -2.5
```

### 9. 项目配置文件 `项目名.config`

可选文件，用于覆盖默认参数 | 每行一个配置项，等号分隔，分号后为注释

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| ClearDepth | -0.3 | 清表深度（负值表示向下） |
| A4WidthMM | 297.0 | A4 图纸宽度（毫米） |
| A4HeightMM | 210.0 | A4 图纸高度（毫米） |
| A4Gap | 30.0 | 图纸边距（毫米） |
| XyzRows | 35 | 地形网格行数 |
| XyzCols | 60 | 地形网格列数 |
| TextScaleFactor | 3.0 | 文字缩放因子 |
| LineSpacingFactor | 1.5 | 行距因子 |

示例：
```
; 项目配置文件
ClearDepth = -0.3    ; 清表深度（负值表示向下）
A4WidthMM = 297.0    ; A4图纸宽度（毫米）
A4HeightMM = 210.0   ; A4图纸高度（毫米）
A4Gap = 30.0         ; 图纸边距（毫米）
XyzRows = 35         ; 地形网格行数
XyzCols = 60         ; 地形网格列数
TextScaleFactor = 3.0        ; 文字缩放因子
LineSpacingFactor = 1.5      ; 行距因子
```

> 📌 配置文件为可选，不存在时使用内置默认值。每行参数说明跟随在分号后，便于阅读。

### 10. 项目文件夹结构

```
lot1/
├── lot1.config          # 项目配置（可选）
├── lot1.pqx             # 平曲线（必需）
├── lot1.sqx             # 竖曲线（必需）
├── lot1.k               # 桩号表（必需）
├── lot1.xyz             # 地形点云（必需）
├── lot1.leftslope       # 左侧路面板块（必需）
├── lot1.rightslope      # 右侧路面板块（必需）
├── lot1.bianpo          # 边坡参数（必需）
├── lot1.leftstructure   # 左侧结构层（可选）
├── lot1.rightstructure  # 右侧结构层（可选）
├── lot1.leftcrossfall   # 左侧横坡变化（可选）
├── lot1.rightcrossfall  # 右侧横坡变化（可选）
└── result/              # 输出目录（自动创建）
    ├── lot1.csv
    ├── lot1.dxf
    └── lot1.html
```

> 📌 所有文件使用相同前缀，程序自动匹配。
