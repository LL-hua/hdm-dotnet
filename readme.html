Go 1.21+ Windows Linux Android

LLhdm-go 测绘自动化系统

基于 Go 语言开发的横断面计算与图纸生成工具，专为测绘与道路工程设计打造。

📖 项目简介

LLhdm-go 是一套完整的测绘横断面自动化处理系统，从地形点云、平曲线、竖曲线、边坡、结构层到横断面生成、方量统计、DXF 图纸输出，全流程自动化。支持 Windows / Linux / Android 跨平台运行，单文件部署，无需任何依赖。

✨ 功能特性

  • 平曲线正算/反算
  • 竖曲线高程计算
  • 地形三角网构建（Delaunay）
  • 横断面切割
  • 填/挖方边坡自动判断
  • 结构层逐层生成
  • 清表线自动偏移
  • 填挖面积精确计算
  • 方量统计 CSV 报表
  • DXF 图纸生成（A4 图幅）
  • HTML/SVG 交互式预览
  • 桩号搜索与可视化
  • 文字大小可调（手机/平板/电脑适配）
  • 项目级配置文件支持

🚀 快速开始

1. 编译运行

# 安装依赖
go mod tidy

# 运行程序
go run main.go

# 编译单文件
go build -ldflags="-s -w" -o LLhdm.exe   # Windows
go build -ldflags="-s -w" -o LLhdm        # Linux/macOS

2. 使用流程

  1. 将项目数据放在以项目名命名的文件夹中（如 lot1/）
  2. 运行程序，选择对应的项目序号
  3. 程序自动完成所有计算，输出到 项目名/result/ 目录

3. 输出成果

  • 项目名.csv — 方量统计报表
  • 项目名.dxf — 横断面图（A4 图幅）
  • 项目名.html — 交互式 SVG 预览（浏览器打开，支持文字大小调节）

🛠️ 数据格式说明

所有数据文件采用 UTF-8 编码，支持逗号、空格或制表符分隔。以 ; 或 # 开头的行为注释行，程序会自动跳过。

1. 平曲线文件 项目名.pqx

第一行：无表头，直接数据 | 8 列
列序名称单位说明
1里程m该段起点里程
2Xm起点 X 坐标
3Ym起点 Y 坐标
4方位角度分秒十进制格式，如 181.062510
5长度m该段长度
6半径1m起点半径，直线为 0
7半径2m终点半径，直线为 0
8转向-左转 1，右转 -1
57415.250, 9635916.871, 433821.286, 181.062510, 150.000, 0, 99999999, 1

2. 竖曲线文件 项目名.sqx

第一行：无表头，直接数据 | 3 列
列序名称单位说明
1里程m变坡点里程
2高程m设计高程
3半径m0 表示无竖曲线
57415.250, 1269.365, 0
60000.000, 1258.000, 20000

3. 桩号表文件 项目名.k

第一行：无表头，直接数据 | 3 列
列序名称单位说明
1里程m计算桩号
2左偏距m通常 0
3右偏距m通常 0
57415.250, 0, 0

4. 地形点云文件 项目名.xyz

第一行：表头（自动跳过） | 3 列
列序名称单位说明
1Xm平面坐标 X
2Ym平面坐标 Y
3Zm高程
9635900.000, 433800.000, 1269.000

5. 路面板块文件 项目名.leftslope / 项目名.rightslope

第一行：表头（自动跳过） | 桩号, 宽度1, 横坡1, 宽度2, 横坡2, ...
列序名称单位说明
1桩号m断面里程
2,4,...宽度m左负右正
3,5,...横坡%左幅负，右幅正
0, -1.5, -2.5, -5.0, -2.5

6. 边坡参数文件 项目名.bianpo

第一行：注释（以 ; 开头） | 每 5 行为一组
行格式说明
1起始桩号, 结束桩号该段落范围
2leftfill, dx, dy, dx, dy, ...左填相对位移
3leftcut, dx, dy, dx, dy, ...左挖相对位移
4rightfill, dx, dy, dx, dy, ...右填相对位移
5rightcut, dx, dy, dx, dy, ...右挖相对位移
; 起始,结束
75300,102300
leftfill,-9.0,-4.5,-1.5,0.0,-14.0,-8.0

7. 结构层文件 项目名.leftstructure / 项目名.rightstructure

第一行：注释（以 ; 开头） | 9 列
列序名称单位说明
1起始桩号m配置起点
2结束桩号m配置终点
3层序-从 1 开始递增
4层名-如 top, CRR, C1
5厚度m层厚
6内台阶宽m内缩宽度
7内坡-内坡率（绝对值）
8外台阶宽m外扩宽度
9外坡-外坡率（绝对值）
99100,117500,1,top,0.05,0,0.0,-5,-2

8. 横坡变化文件 项目名.leftcrossfall / 项目名.rightcrossfall

第一行：表头（自动跳过） | 2 列
列序名称单位说明
1桩号m控制点里程
2横坡%线性插值
0, -2.5
50000, -2.5

9. 项目配置文件 项目名.config

可选文件，用于覆盖默认参数 | 每行一个配置项，等号分隔，分号后为注释
参数名默认值说明
ClearDepth-0.3清表深度（负值表示向下）
A4WidthMM297.0A4 图纸宽度（毫米）
A4HeightMM210.0A4 图纸高度（毫米）
A4Gap30.0图纸边距（毫米）
XyzRows35地形网格行数
XyzCols60地形网格列数
TextScaleFactor3.0文字缩放因子
LineSpacingFactor1.5行距因子
; 项目配置文件
ClearDepth = -0.3 ; 清表深度（负值表示向下）
A4WidthMM = 297.0 ; A4图纸宽度（毫米）
A4HeightMM = 210.0 ; A4图纸高度（毫米）
A4Gap = 30.0 ; 图纸边距（毫米）
XyzRows = 35 ; 地形网格行数
XyzCols = 60 ; 地形网格列数
TextScaleFactor = 3.0 ; 文字缩放因子
LineSpacingFactor = 1.5 ; 行距因子
📌 配置文件为可选，不存在时使用内置默认值。每行参数说明跟随在分号后，便于阅读。
